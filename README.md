## Windows 11ನಲ್ಲಿ ಸ್ಥಳೀಯವಾಗಿ ನೋಡುವುದು

File Explorerನಲ್ಲಿ C:\GroceryWebsite ತೆರೆಯಿರಿ. index.html ಮೇಲೆ ಎರಡು ಬಾರಿ click ಮಾಡಿ. ಬದಲಾವಣೆ ನಂತರ ಬ್ರೌಸರ್‌ನಲ್ಲಿ Ctrl+F5 ಒತ್ತಿ.

## ಬೆಲೆಗಳನ್ನು ಬದಲಾಯಿಸುವುದು

index.htmlನಲ್ಲಿ ಉತ್ಪನ್ನದ data-price ಮೌಲ್ಯವನ್ನು ನಿಜವಾದ ರೂಪಾಯಿ ಬೆಲೆಗೆ ಬದಲಿಸಿ. ಉದಾಹರಣೆ: <strong data-price="60">Ask in store</strong>. ಬೆಲೆ ತಿಳಿದಿಲ್ಲದಿದ್ದರೆ ಖಾಲಿಯೇ ಬಿಡಿ; ಊಹಿಸಿದ ಬೆಲೆ ಪ್ರಕಟಿಸಬೇಡಿ.

## ಚಿತ್ರಗಳು ಮತ್ತು ಭಾಷೆ

ಚಿತ್ರಗಳು images/ ಫೋಲ್ಡರ್‌ನಲ್ಲಿವೆ. ಮ್ಯಾನೇಜರ್ ಚಿತ್ರಗಳ ಹೆಸರುಗಳನ್ನು ಬದಲಿಸಿದರೆ index.htmlನ image path ಕೂಡ ಬದಲಿಸಿ. ಭಾಷೆ ಬದಲಿಸಲು ಪುಟದ ಮೇಲಿರುವ ಕನ್ನಡ/English ಬಟನ್ ಬಳಸಿ.

## GitHub Pages ನಿರ್ವಹಣೆ

ಈ repositoryಯ main branch‌ನ root‌ನಿಂದ GitHub Pages ಪ್ರಕಟಿಸುತ್ತದೆ. ಬದಲಿಸಿದ ಕಡತಗಳನ್ನು commit ಮಾಡಿದ ನಂತರ Actionsನಲ್ಲಿ Pages build ಯಶಸ್ವಿಯಾಗಿದೆ ಎಂದು ನೋಡಿ. ಮೇಲಿನ Pages URL ತೆರೆಯಿಸಿ English/Kannada ಪಠ್ಯ, ಚಿತ್ರಗಳು ಮತ್ತು ಅಂಗಡಿಯ Maps ಬಟನ್ ಪರಿಶೀಲಿಸಿ.
