# ದುರ್ಗಾ ಪರಮೇಶ್ವರಿ ಕಿರಾಣಿ ಆ್ಯಂಡ್ ಜನರಲ್ ಸ್ಟೋರ್

## ವೆಬ್‌ಸೈಟ್ ತೆರೆಯುವುದು — Windows 11
1. Windows ಕೀ + E ಒತ್ತಿ File Explorer ತೆರೆಯಿರಿ.
2. ವಿಳಾಸ ಪಟ್ಟಿಯಲ್ಲಿ `C:\GroceryWebsite` ಎಂದು ನಮೂದಿಸಿ Enter ಒತ್ತಿರಿ.
3. `index.html` ಮೇಲೆ ಎರಡು ಬಾರಿ ಕ್ಲಿಕ್ ಮಾಡಿ. ಅದು ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ತೆರೆಯುತ್ತದೆ.
4. ಮೇಲಿನ `ಕನ್ನಡ / English` ಗುಂಡಿಯಿಂದ ಭಾಷೆ ಬದಲಾಯಿಸಿ. ಮೊಬೈಲ್‌ನಲ್ಲಿ `ಮೆನು / Menu` ಗುಂಡಿ ಒತ್ತಿ ವಿಭಾಗಗಳನ್ನು ತೆರೆಯಿರಿ.
5. ಈ ಪ್ರಕಟಿತ ಆವೃತ್ತಿಯಲ್ಲಿ ಫೋನ್ ಸಂಖ್ಯೆಗಳು ಮತ್ತು ನೇರ WhatsApp ಲಿಂಕ್‌ಗಳನ್ನು ತೆಗೆದುಹಾಕಲಾಗಿದೆ. ಆರ್ಡರ್ ಮಾಡಲು ಅಂಗಡಿಗೆ ಬನ್ನಿ.

## ವ್ಯವಸ್ಥಾಪಕರ ಮೂಲ ಫೋಟೋಗಳು
1. ಎರಡೂ ಮೂಲ ಫೋಟೋಗಳು ಈಗಾಗಲೇ `C:\GroceryWebsite\images` ಫೋಲ್ಡರ್‌ನಲ್ಲಿವೆ.
2. `manager1-shivanand.jpg` ಎಡಭಾಗದಲ್ಲಿ ಬಿಳಿ ಅಂಗಿಯ ಶ್ರೀ ಶಿವಾನಂದ ಶಿವಲಿಂಗ ಗೋಣಿಯವರ ಫೋಟೋ.
3. `manager2-mahantesh.jpg` ಬಲಭಾಗದಲ್ಲಿ ಶ್ರೀ ಮಹಾಂತೇಶ ಶಿವಲಿಂಗ ಗೋಣಿಯವರ ಫೋಟೋ.
4. `index.html` ಮರುಲೋಡ್ ಮಾಡಿ. ವೃತ್ತಾಕಾರದ ಫ್ರೇಮ್‌ನಲ್ಲಿ ಕಾಣದಿದ್ದರೆ `styles.css` ನ `.manager-photo` ನಿಯಮವನ್ನು ಪರಿಶೀಲಿಸಿ.
## ಬೆಲೆ ಮತ್ತು ಆಫರ್ ತಿದ್ದುಪಡಿ
1. `index.html` ಅನ್ನು Notepad ಅಥವಾ VS Codeನಲ್ಲಿ ತೆರೆಯಿರಿ.
2. ಉತ್ಪನ್ನದ ಬೆಲೆ ಅಂಶದಲ್ಲಿರುವ `data-price=""` ಒಳಗೆ ಅಂಗಡಿಯ ನಿಜವಾದ ಬೆಲೆಯನ್ನು ಮಾತ್ರ ಹಾಕಿ. ಉದಾಹರಣೆಗೆ ಅಂಗಡಿಯ ನಿಜವಾದ ಬೆಲೆ ₹60 ಆಗಿದ್ದರೆ `data-price="60"` ಎಂದು ಬರೆಯಿರಿ. ಬೆಲೆ ಖಾಲಿ ಇದ್ದರೆ “ಬೆಲೆ ಅಂಗಡಿಯಲ್ಲಿ ವಿಚಾರಿಸಿ” ಎಂದು ಕಾಣುತ್ತದೆ.
3. `Ctrl+S` ಒತ್ತಿ ಉಳಿಸಿ; ಬ್ರೌಸರ್‌ನಲ್ಲಿ `Ctrl+F5` ಒತ್ತಿ ಮರುಲೋಡ್ ಮಾಡಿ.
## ಅಂಗಡಿಯ ಚಿತ್ರಗಳು
- ನಿಮ್ಮಿಂದ ಬಂದ ಐದು ಅಂಗಡಿ ಚಿತ್ರಗಳು `images` ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಇವೆ.
- ಶಿವಾನಂದ ಮತ್ತು ಮಹಾಂತೇಶರ ಮೂಲ ಫೋಟೋಗಳು `manager1-shivanand.jpg`, `manager2-mahantesh.jpg` ಹೆಸರಿನಲ್ಲಿ ಈಗಾಗಲೇ ಸೇರಿವೆ. SVG placeholderಗಳು fallback ಆಗಿ ಉಳಿದಿವೆ.
- ವೆಬ್‌ಸೈಟ್ ಚಿತ್ರಗಳು projectನ `images` ಫೋಲ್ಡರ್‌ನಿಂದ ಲೋಡ್ ಆಗುತ್ತವೆ. ಕನ್ನಡದ Noto Sans ಮತ್ತು ಇತರೆ Google Fonts ಲೋಡ್ ಮಾಡಲು ಇಂಟರ್ನೆಟ್ ಸಂಪರ್ಕ ಸಹಾಯಕ; ಸಂಪರ್ಕವಿಲ್ಲದಿದ್ದರೂ system fallback font ಬಳಸುತ್ತದೆ.
## ಕಾರ್ಟ್ ಬಳಕೆ
1. ಉತ್ಪನ್ನದ ಕೆಳಗಿನ **ಕಾರ್ಟ್‌ಗೆ ಸೇರಿಸಿ** ಗುಂಡಿ ಒತ್ತಿದರೆ ಆ ವಸ್ತು ಕಾರ್ಟ್‌ಗೆ ಸೇರುತ್ತದೆ.
2. ಕಾರ್ಟ್‌ನಲ್ಲಿ ಪ್ರಮಾಣವನ್ನು + / − ಮೂಲಕ ಬದಲಾಯಿಸಿ ಅಥವಾ ವಸ್ತುವನ್ನು ತೆಗೆದುಹಾಕಿ.
3. ಬೇರೆ ಯಾವುದೇ ಕಿರಾಣಿ ವಸ್ತುವಿನ ಹೆಸರನ್ನು ನಮೂದಿಸಿ **ವಸ್ತು ಸೇರಿಸಿ** ಒತ್ತಬಹುದು.
4. **ವಸ್ತುಗಳ ಪಟ್ಟಿ ನಕಲಿಸಿ** ಒತ್ತಿದಾಗ ಪಟ್ಟಿಯನ್ನು ಅಂಗಡಿಗೆ ತೋರಿಸಲು ನಕಲಿಸಲಾಗುತ್ತದೆ. ಬೆಲೆ/ಲಭ್ಯತೆ ಅಂಗಡಿಯಲ್ಲಿ ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ; ಯಾವುದೇ ಬೆಲೆಯನ್ನು ಊಹಿಸಿಲ್ಲ.
5. ಕಾರ್ಟ್ ಈ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಉಳಿಯುತ್ತದೆ; ಮರುತೆರೆದಾಗಲೂ ಪಟ್ಟಿಯನ್ನು ತೋರಿಸುತ್ತದೆ.


## ಕ್ಯಾಟಲಾಗ್, ಉಲ್ಲೇಖ ದರ ಮತ್ತು WhatsApp ಕಾರ್ಟ್

- products.js ಫೈಲ್‌ನಲ್ಲಿ ಉತ್ಪನ್ನದ ಹೆಸರು, ಕನ್ನಡ ಹೆಸರು, ಪ್ಯಾಕ್ ಗಾತ್ರ, ವರ್ಗ, ಉಲ್ಲೇಖ ದರ ಮತ್ತು ದರದ ಮೂಲದ ಲಿಂಕ್ ಇವೆ.
- ದರ ಬದಲಿಸಲು ಉತ್ಪನ್ನದ ಸಾಲಿನಲ್ಲಿ price: 371 ಇರುವ ಸಂಖ್ಯೆಯನ್ನು ಬದಲಿಸಿ. ದಶಮಾಂಶ ದರಕ್ಕೆ price: 173.25 ಎಂದು ಬರೆಯಬಹುದು. ಅಂಗಡಿಯ ನಿಜವಾದ ಮಾರಾಟ ದರವನ್ನು ಮಾಲೀಕರು ಖಚಿತಪಡಿಸಿದ ನಂತರ ಮಾತ್ರ ನಮೂದಿಸಿ.
- ಪ್ರತಿ ಉತ್ಪನ್ನದ “Price source / ದರದ ಮೂಲ” ಲಿಂಕ್ ಅನ್ನು ತೆರೆಯುವುದರಿಂದ ಆನ್‌ಲೈನ್ ಉಲ್ಲೇಖವನ್ನು ಪರಿಶೀಲಿಸಬಹುದು. ಆನ್‌ಲೈನ್ ದರಗಳು ಪ್ರದೇಶ ಮತ್ತು ಸಮಯಕ್ಕೆ ತಕ್ಕಂತೆ ಬದಲಾಗುತ್ತವೆ; ಪುಟದಲ್ಲಿನವು ಅಂಗಡಿಯ ಖಚಿತ ದರವಲ್ಲ.
- ಈಗಿನ ಉತ್ಪನ್ನ ಚಿತ್ರಗಳು ಪ್ರತಿನಿಧಿ SVG ಚಿತ್ರಗಳು. ನಿಖರ ಬ್ರ್ಯಾಂಡ್ ಪ್ಯಾಕ್ ಫೋಟೋ ಸೇರಿಸಲು ಚಿತ್ರವನ್ನು images ಫೋಲ್ಡರ್‌ಗೆ ಸೇರಿಸಿ, script.js ಫೈಲ್‌ನ ಉತ್ಪನ್ನ ಚಿತ್ರ ರಚನೆಗೆ ಆ ಫೈಲ್ ಮಾರ್ಗವನ್ನು ಜೋಡಿಸಿ.
- ವಸ್ತುಗಳನ್ನು ಕಾರ್ಟ್‌ಗೆ ಸೇರಿಸಿ ಪ್ರಮಾಣ ಬದಲಾಯಿಸಬಹುದು, ತೆಗೆದುಹಾಕಬಹುದು, ಪಟ್ಟಿಯನ್ನು ನಕಲಿಸಬಹುದು ಅಥವಾ WhatsApp ಮೂಲಕ ಅಂಗಡಿಗೆ ಕಳುಹಿಸಬಹುದು. ಅಂಗಡಿಯ WhatsApp ಸಂಪರ್ಕವು ಲಿಂಕ್‌ನಲ್ಲಿ ಮಾತ್ರ ಇದೆ; ಪುಟದ ಪಠ್ಯದಲ್ಲಿ ಸಂಖ್ಯೆ ತೋರಿಸುವುದಿಲ್ಲ.
- ಕಾರ್ಟ್‌ನಲ್ಲಿ ಹೊಸದಾಗಿ ಬೇರೆ ವಸ್ತುವಿನ ಹೆಸರನ್ನೂ ಸೇರಿಸಬಹುದು. ಲಭ್ಯತೆ ಮತ್ತು ಅಂತಿಮ ದರವನ್ನು ಅಂಗಡಿಯೊಂದಿಗೆ ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ.
