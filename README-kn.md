# ದುರ್ಗಾ ಪರಮೇಶ್ವರಿ ಕಿರಾಣಿ ಆ್ಯಂಡ್ ಜನರಲ್ ಸ್ಟೋರ್

## ವೆಬ್‌ಸೈಟ್ ತೆರೆಯುವುದು — Windows 11
1. Windows ಕೀ + E ಒತ್ತಿ File Explorer ತೆರೆಯಿರಿ.
2. ವಿಳಾಸ ಪಟ್ಟಿಯಲ್ಲಿ `C:\GroceryWebsite` ಎಂದು ನಮೂದಿಸಿ Enter ಒತ್ತಿರಿ.
3. `index.html` ಮೇಲೆ ಎರಡು ಬಾರಿ ಕ್ಲಿಕ್ ಮಾಡಿ. ವೆಬ್‌ಸೈಟ್ ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ತೆರೆಯುತ್ತದೆ.
4. `ಕನ್ನಡ / English` ಆಯ್ಕೆಯಿಂದ ಭಾಷೆ ಬದಲಾಯಿಸಿ. ಮೊಬೈಲ್‌ನಲ್ಲಿ `ಮೆನು / Menu` ಆಯ್ಕೆಮಾಡಿ ವಿಭಾಗಗಳನ್ನು ತೆರೆಯಿರಿ.

## ಉತ್ಪನ್ನ ಕ್ಯಾಟಲಾಗ್ ಮತ್ತು ಬೆಲೆಗಳು
- 43 ಸಾಮಾನ್ಯ ದಿನಸಿ ವಸ್ತುಗಳು ಆರು ವರ್ಗಗಳಲ್ಲಿ ಇವೆ. ಉತ್ಪನ್ನಗಳನ್ನು ಹುಡುಕಲು ಅಥವಾ ವರ್ಗದಿಂದ ಆಯ್ಕೆಮಾಡಲು ಕ್ಯಾಟಲಾಗ್‌ನ ಹುಡುಕಾಟ ಮತ್ತು ಫಿಲ್ಟರ್ ಬಳಸಿ.
- ಉತ್ಪನ್ನಗಳ ಹೆಸರು, ಪ್ಯಾಕ್ ಗಾತ್ರ, ವರ್ಗ, ಉಲ್ಲೇಖ ಬೆಲೆ ಮತ್ತು ಮೂಲದ ಲಿಂಕ್ `products.js` ಫೈಲ್‌ನಲ್ಲಿವೆ. `price` ಸಂಖ್ಯೆಯನ್ನು ಬದಲಿಸಿದರೆ ತೋರಿಸುವ ಬೆಲೆ ಬದಲಾಗುತ್ತದೆ.
- ಕಾಣುವ ಬೆಲೆಗಳು BigBasketನಲ್ಲಿ ಪರಿಶೀಲಿಸಿದ ಆನ್‌ಲೈನ್ ಉಲ್ಲೇಖ ದರಗಳು. ಪ್ರದೇಶ, ದಿನ ಮತ್ತು ಆಫರ್‌ಗಳಿಂದ ಬೆಲೆ ಬದಲಾಗಬಹುದು; ಅವು ಅಂಗಡಿಯ ಖಚಿತ ಮಾರಾಟ ಬೆಲೆಗಳಲ್ಲ. ಪ್ರತಿ ವಸ್ತುವಿನ ಮೂಲದ ಲಿಂಕ್‌ನಲ್ಲಿ ವಿವರ ಪರಿಶೀಲಿಸಿ.
- ಈಗ ಉತ್ಪನ್ನಗಳಿಗೆ ಕಾಣುವ ಚಿತ್ರಗಳು ಪ್ರತಿನಿಧಿ SVG ಕಲಾಕೃತಿಗಳು; ಅವು ನಿಖರ ಬ್ರ್ಯಾಂಡ್ ಪ್ಯಾಕ್ ಚಿತ್ರಗಳಲ್ಲ. ನಿಜವಾದ ಉತ್ಪನ್ನ ಫೋಟೋ ಸೇರಿಸಲು ಚಿತ್ರವನ್ನು `images/products/` ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಇಟ್ಟು, `script.js`ನ ಉತ್ಪನ್ನ ಚಿತ್ರ ಪ್ರದರ್ಶನವನ್ನು ಆ ಫೈಲ್ ಮಾರ್ಗಕ್ಕೆ ಹೊಂದಿಸಿ.

## ಕಾರ್ಟ್ ಮತ್ತು WhatsApp ಆರ್ಡರ್
1. ಉತ್ಪನ್ನದ **ಕಾರ್ಟ್‌ಗೆ ಸೇರಿಸಿ** ಗುಂಡಿ ಒತ್ತಿ; `+` / `−` ಮೂಲಕ ಪ್ರಮಾಣ ಬದಲಾಯಿಸಿ ಅಥವಾ ಕಾರ್ಟ್‌ನಿಂದ ತೆಗೆದುಹಾಕಿ.
2. ಪಟ್ಟಿಯಲ್ಲಿ ಇಲ್ಲದ ವಸ್ತುವಿನ ಹೆಸರನ್ನು ಕಾರ್ಟ್‌ನಲ್ಲಿ ನಮೂದಿಸಿ ಸೇರಿಸಬಹುದು.
3. ಕಾರ್ಟ್‌ನಲ್ಲಿರುವ ಪಟ್ಟಿಯನ್ನು ನಕಲಿಸಬಹುದು ಅಥವಾ WhatsApp ಮೂಲಕ ಅಂಗಡಿಗೆ ಕಳುಹಿಸಬಹುದು. WhatsApp ಗುಂಡಿ ಅಂಗಡಿಯ ಆಯ್ದ ಸಂಪರ್ಕಕ್ಕೆ ಪೂರ್ವಭರಿತ ಸಂದೇಶ ತೆರೆಯುತ್ತದೆ; ಫೋನ್ ಸಂಖ್ಯೆ ಪುಟದ ಪಠ್ಯದಲ್ಲಿ ಕಾಣಿಸುವುದಿಲ್ಲ.
4. ಕಾರ್ಟ್ ನಿಮ್ಮ ಬ್ರೌಸರ್‌ನಲ್ಲಿ ಉಳಿಯುತ್ತದೆ. ಒಟ್ಟು ಮೊತ್ತವು ಉಲ್ಲೇಖ ದರಗಳಿಂದ ಲೆಕ್ಕವಾಗುತ್ತದೆ; ಅಂಗಡಿಯ ಅಂತಿಮ ಬೆಲೆ ಮತ್ತು ಲಭ್ಯತೆಯನ್ನು ಖಚಿತಪಡಿಸಿಕೊಳ್ಳಿ.

## ಇತರೆ ಮಾಹಿತಿ ಮತ್ತು ಚಿತ್ರಗಳು
- ಮ್ಯಾನೇಜರ್‌ಗಳ ಮೂಲ ಫೋಟೋಗಳು `images/manager1-shivanand.jpg` ಮತ್ತು `images/manager2-mahantesh.jpg` ಕಡತಗಳಲ್ಲಿವೆ.
- ಅಂಗಡಿಯ ಫೋಟೋಗಳು `images/` ಫೋಲ್ಡರ್‌ನಲ್ಲಿವೆ. ಅಂಗಡಿ ಸ್ಥಳ, ಸಂಪರ್ಕ, ಆಫರ್‌ಗಳು ಮತ್ತು ಇತರೆ ಸೇವೆಗಳು ವೆಬ್‌ಸೈಟ್‌ನ ವಿಭಾಗಗಳಲ್ಲಿ ಕಾಣುತ್ತವೆ.
- ಬೆಲೆ ಅಥವಾ ವಿಷಯ ಬದಲಿಸಿದ ನಂತರ ಕಡತ ಉಳಿಸಿ, ಬ್ರೌಸರ್‌ನಲ್ಲಿ `Ctrl+F5` ಒತ್ತಿ ಮರುಲೋಡ್ ಮಾಡಿ.

## GitHub Pages ಪ್ರಕಟಣೆ
ಈ ವೆಬ್‌ಸೈಟ್‌ನ ಮೂಲ ಕಡತಗಳನ್ನು GitHub repositoryಗೆ commit ಮಾಡಿದ ನಂತರ GitHub Pages ಅವುಗಳನ್ನು ಪ್ರಕಟಿಸುತ್ತದೆ. repositoryಯಲ್ಲಿ `index.html`, `styles.css`, `script.js`, `products.js`, READMEಗಳು ಮತ್ತು ಸಂಪೂರ್ಣ `images/` ಫೋಲ್ಡರ್ ಇರಲಿ. GitHubನಲ್ಲಿ **Settings → Pages** ತೆರೆಯಿರಿ; **Deploy from a branch**, `main`, `/(root)` ಆಯ್ಕೆಮಾಡಿ. Actionsನಲ್ಲಿ deploy ಯಶಸ್ವಿಯಾದ ಮೇಲೆ Pages ಪುಟ ತೋರಿಸುವ URL ತೆರೆಯಿರಿ. ಪ್ರಕಟಿತ ವೆಬ್‌ಸೈಟ್ ಸಾರ್ವಜನಿಕರಿಗೆ ಕಾಣುತ್ತದೆ; repositoryಯ visibility ಮತ್ತು ಅದರಲ್ಲಿರುವ ಮಾಹಿತಿಯನ್ನು ಪರಿಶೀಲಿಸಿ.
