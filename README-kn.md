## Windows 11ನಲ್ಲಿ website ನೋಡುವುದು

File Explorerನಲ್ಲಿ C:\GroceryWebsite ತೆರೆಯಿರಿ. index.html ಮೇಲೆ ಎರಡು ಬಾರಿ click ಮಾಡಿ. ಬದಲಿಸಿದ ನಂತರ browserನಲ್ಲಿ Ctrl+F5 ಒತ್ತಿ.

## ಬೆಲೆ ಬದಲಾವಣೆ

index.htmlನಲ್ಲಿ ಉತ್ಪನ್ನದ data-price ಮೌಲ್ಯಕ್ಕೆ ಅಂಗಡಿಯ ನಿಜವಾದ ಬೆಲೆಯನ್ನು ರೂಪಾಯಿಗಳಲ್ಲಿ ಹಾಕಿ. ಉದಾಹರಣೆ: <strong data-price="60">Ask in store</strong>. ಬೆಲೆ ಖಚಿತವಿಲ್ಲದಿದ್ದರೆ ಖಾಲಿ ಬಿಡಿ; ಬೆಲೆ ಊಹಿಸಬೇಡಿ.

## ಚಿತ್ರಗಳು ಮತ್ತು ಭಾಷೆ

ಚಿತ್ರಗಳನ್ನು images/ ಫೋಲ್ಡರ್‌ನಲ್ಲಿ ಇಡಿ. manager ಚಿತ್ರಗಳ ಹೆಸರನ್ನು ಬದಲಿಸಿದರೆ index.htmlನಲ್ಲಿನ image path ಕೂಡ ಬದಲಿಸಿ. ಪುಟದ ಭಾಷಾ ಬಟನ್ ಬಳಸಿ Kannada ಮತ್ತು English ನಡುವೆ ಬದಲಾಯಿಸಿ.
